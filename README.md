# 南投國中 115 學年度二年級隔宿露營 · 尖山埤探索相簿

本專案收錄南投縣立南投國民中學 115 學年度國二隔宿露營（台南尖山埤江南渡假村，115/10/27～10/28）全體師生之珍貴活動相片與影音全紀錄。

## 🌟 網頁特色

- **雙層分類導覽體系**：
  - **第一層 9 大主題標籤**：6 個班級／隨隊隊輔（`201 三元`、`202 小郭`、`203 阿犬`、`204 木木`、`205+206+207 哈任`、`207 五千`）及 3 大探索專區（`獨木橋`、`繩結 盲蛇取物`、`跳繩+水彈`）。
  - **第二層活動即時篩選**：快樂啟程、環境認識安全檢查、開訓始業式、帳棚搭設示範、童軍核心技能、野炊廚藝競賽、營火晚會、早餐合菜、山訓與探索教育、BBQ烤肉饗宴、結訓典禮等。
- **AI 內容文字說明**：每張相片均具備貼近現場情境之生動文字導讀。
- **全螢幕燈箱與高解析檢視**：支援鍵盤左右鍵切換、幻燈片瀏覽及原圖下載。
- **影音整合**：支援現場活動 MOV / MP4 影片即時播放。
- **即時全文搜尋**：支援關鍵字即時比對活動、班級、檔名與圖說。
